# Projeto Carflix

## Sobre o projeto

Esse projeto consiste na criação de um site simples de venda de carros utilizando **HTML, CSS e JavaScript**.
A ideia foi simular um site de concessionária onde o usuário pode visualizar alguns carros disponíveis, ver o preço e clicar no botão de compra.

Também foi criada uma página especial com **carros de Fórmula 1 de coleção**, com réplicas de carros históricos da categoria.

O objetivo principal foi praticar a **estruturação de páginas web**, organização do código e aplicação de conceitos básicos de **usabilidade e navegação**.

---

## Estrutura do site

O site possui algumas páginas principais:

* **index.html**
  Página inicial com carros em destaque, supercarros e sedans de luxo.

* **colecao.html**
  Página com carros históricos da Fórmula 1.

* **compra.html**
  Página que simula a compra do veículo selecionado.

---

## Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

* **HTML** → estrutura das páginas
* **CSS** → estilização e layout do site
* **JavaScript** → interação básica com o usuário (ex: botão de compra)

---

## Ideia de usabilidade

A ideia de usabilidade foi deixar o site **simples e fácil de navegar**, simulando um site real de carros.

Alguns pontos pensados:

* Layout organizado em **cards de veículos**
* Botão de **comprar direto em cada carro**
* Separação dos veículos em **categorias**
* Página específica para **carros de coleção**
* Navegação simples entre as páginas

A intenção foi criar algo que qualquer pessoa consiga usar **sem precisar pensar muito**, apenas entrar, ver os carros e clicar no que quiser comprar.
